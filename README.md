# Simulator Rx-9

Rotary engine simulator web app with its RX-9 app icon.

## Publish on GitHub Pages (phone or computer)
1. Create a **Public** repository named `simulator-rx-9`.
2. Upload the CONTENTS of this ZIP to the repository root (not the ZIP itself).
3. Confirm the root contains `index.html`, `script.js`, `style.css`, `manifest.webmanifest`, and the `icons` folder.
4. Open Settings > Pages. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the Pages deployment to finish, then open the URL shown in the Pages section.

The Three.js library loads from a CDN, so internet access is needed on first load.
